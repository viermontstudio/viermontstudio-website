# V2 · Experiencia Interactiva

## Propósito

Transformar un portfolio tradicional en una experiencia interactiva.

## Concepto

Durante esta fase, Viermont Studio deja de ser únicamente una galería de proyectos para convertirse en un espacio explorable.

Aparecen nuevos elementos que permiten al visitante descubrir información de formas diferentes, alejándose del formato clásico de portfolio personal.

## Conceptos clave

- README interactivo
- Terminal simulada
- Exploración de perfil
- Interacción y experiencia de usuario

## Objetivos principales

- Crear una experiencia memorable.
- Diferenciar la web de un portfolio convencional.
- Introducir elementos interactivos.
- Reforzar la identidad del proyecto.

## Principales incorporaciones

- Currículum inspirado en un README de GitHub.
- Terminal interactiva simulada.
- Primeros experimentos con contenido dinámico.

## Aprendizajes

La interacción aportó personalidad y diferenciación al proyecto, aunque también comenzó a generar cierta repetición narrativa entre distintas secciones.
