# Viermont Studio - Documentación de Versiones

# V1 · Fundación

## Propósito

Nacimiento de Viermont Studio.

## Concepto

La primera versión del proyecto surge con el objetivo de unir dos disciplinas que siempre han formado parte de mi trayectoria: el arte y la tecnología.

Esta etapa se centra en construir una identidad visual propia y en trasladar al entorno digital una forma de entender la creatividad donde diseño, arte y código pueden convivir dentro de un mismo espacio.

## Conceptos clave

- Arte + Código
- Primer portfolio digital
- Primera identidad visual
- Primer mensaje de marca

## Frase representativa

> "La creatividad es el algoritmo. El código, mi pincel."

## Objetivos principales

- Crear una presencia digital propia.
- Mostrar trabajos artísticos.
- Explorar la integración entre creatividad y tecnología.
- Definir las bases de Viermont Studio.

## Aprendizajes

Esta versión permitió establecer los primeros pilares visuales y conceptuales del proyecto, aunque la narrativa seguía planteando el arte y la tecnología como dos disciplinas separadas que comenzaban a encontrarse.
