# V3 · Convergencia

## Propósito

Unificar experiencia, aprendizaje y proyectos reales dentro de una misma plataforma.

## Concepto

Esta fase marca la transición desde una web centrada en la presentación personal hacia una herramienta capaz de reflejar la evolución profesional y tecnológica del proyecto.

Incluyó distintas propuestas exploradas a través de Google AI Studio. Los archivos presentes en la carpeta representan variaciones, pruebas visuales y cambios evaluados durante el proceso.

La integración de GitHub, el peso creciente del desarrollo de software y la incorporación de la inteligencia artificial comienzan a redefinir la identidad de Viermont Studio.

## Conceptos clave

- GitHub
- Proyectos reales
- Desarrollo de software
- Aprendizaje continuo
- Inteligencia artificial

## Objetivos principales

- Sustituir contenido conceptual por proyectos reales.
- Conectar la web con GitHub.
- Reflejar la evolución tecnológica del proyecto.
- Consolidar la identidad profesional.

## Aprendizajes

La incorporación de proyectos reales incrementó la credibilidad técnica del portfolio, aunque todavía existían redundancias entre algunas secciones narrativas.
